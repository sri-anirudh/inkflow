# apps/web — InkFlow Frontend

Next.js (App Router, TypeScript). Not containerized locally — runs directly via `npm run dev` (Development Environment §2).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Lint / format / type-check

```bash
npm run lint
npm run format
npx tsc --noEmit
```
